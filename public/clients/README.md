# Client logos

Logos shown in the "Our clients" section. Each file is referenced from `src/data/clients.ts`
(the `logo` field). To add a client, put the logo here and add a line to that file, then rebuild.
SVG or a cropped transparent PNG looks best. If a file is missing, the client's name shows as text.

- `iqip-logo.svg` - iQiP
- `ansi-techno-logo.png` - Ansi Techno (transparent, cropped from `ansi-logo.jpg`)
- `birtiktech-logo.png` - Birtik Tech Pvt Ltd (blue on transparent, made from `birtiktech.png`)
